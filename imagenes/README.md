# Imágenes

Fotografías ordenadas por sesión; funcionan como evidencia técnica del trabajo del equipo.

Sube aquí, idealmente en subcarpetas por fecha (por ejemplo `2026-08-20/`, `2026-08-31/`, `2026-09-10/`), evidencia como:

- Fotografía del equipo (sesión 20-08-2026).
- Fotografía real del mapa conceptual (sesión 31-08-2026).
- Fotografía real del mapa de empatía (sesión 31-08-2026).
- Evidencia visual usada en el pitch del Hito 1 (sesión 10-09-2026).

Enlaza cada imagen desde el archivo de sesión correspondiente en [`sesiones/`](../sesiones), por ejemplo:

```markdown
![Mapa conceptual](../imagenes/2026-08-31/mapa-conceptual.jpg)
```

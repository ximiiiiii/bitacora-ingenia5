## Síntesis crítica de avance (primeras dos semanas)

**Qué se propuso el equipo:** comprender y delimitar el desafío de caracterización de usuarios del Hub Providencia, evitando asumir que la solución ya estaba definida.

**Qué se hizo:** se constituyó formalmente Ingenia 5; se definieron normas, roles y compromisos; se analizó la ficha del desafío; se construyeron un mapa conceptual y un mapa de empatía; se separó evidencia de supuestos; se formularon preguntas de investigación; se revisó información oficial del contexto y se preparó el Hito 1 y su pitch.

**Qué se aprendió o cambió:** el desafío entregado no equivale automáticamente a una definición validada del problema. La ausencia de una aplicación o tecnología no debe formularse como problema, y varias afirmaciones del mapa de empatía son hipótesis. El foco se desplazó desde pensar anticipadamente en una solución hacia comprender el proceso actual, las necesidades de información y los supuestos que requieren evidencia.

**Qué debe hacerse después:** observación del flujo actual, entrevista al equipo de gestión, conversaciones con personas usuarias, revisión de registros existentes y un levantamiento piloto acotado. Con esa evidencia se confirmarán o refutarán los supuestos, se ajustará la delimitación del problema y recién entonces se avanzará hacia requerimientos y alternativas de solución.
